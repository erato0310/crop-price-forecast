# 웹앱 — 전북 상추 가격

전북 시군·읍면별 상추 산지가격을 보여주는 **서버 없는 정적 웹앱**입니다.

예측은 `export_lettuce_webapp.py` / `forecast_2027.py`가 미리 다 계산해 두므로,
웹앱은 그 결과 JSON 둘만 읽습니다. **백엔드도, 데이터베이스도, 서버 비용도 없습니다** —
정적 호스팅에 올리면 그대로 동작합니다.

## 구성

```
webapp/
  lettuce.html                    화면·스타일·렌더링을 한 파일에 담음 (외부 라이브러리 없음)
  index.html                      → lettuce.html 로 보내는 이동 페이지
  data/lettuce_app.json           시군 13 / 읍면 63, 주간 가격·품종·4주 예측 (약 1.2MB)
  data/lettuce_forecast_2027.json 2027년까지 월별 전망 (약 194KB)
  data/jeonbuk_geo.json           전북 시군 경계 원본 (build_geo.py 산출물)
```

지도 경계는 `lettuce_app.json` 안의 `geo`에 이미 들어 있어서, 앱이 뜰 때
`jeonbuk_geo.json`을 따로 읽지는 않습니다. 외부 CDN·폰트·라이브러리를 하나도
쓰지 않아 폐쇄망에서도 동작합니다.

## 기능

- **시군 지도** — 기간(8주/6개월/1년/3년/전체/직접)을 고르면 시군별 평균 원/kg으로
  색칠됩니다. 평균·최고·최저를 전환해 볼 수 있습니다.
- **읍면 드릴다운** — 시군을 누르면 그 시군의 읍면별 순위가 열리고,
  최고·최저가 **발생한 주**가 함께 나옵니다.
- **주간 추이** — 그 주의 최저~최고 범위를 띠로, 주간 평균을 실선으로 그리고
  4주 예측을 80% 구간과 함께 점선으로 잇습니다.
- **2027년까지 월별 전망** — 지평별로 쓴 방법(1~3개월은 모델, 4개월+는 계절평균×수준보정)과
  그 방법의 오차율을 같이 적습니다.
- **품종 구성** — 물량 비중과 품종별 평균가.

## 숫자를 오해하지 않게 하는 장치

- **모든 가격은 원/kg입니다.** 도매시장 원자료는 상자단가라 상자무게로 나눠 환산했습니다.
  4kg 상자가 13만원에 낙찰되면 상자단가 130,000원 = 32,500원/kg입니다.
  "상추가 10만원 넘었다"는 기억은 대개 상자단가이므로 **최고 상자단가를 표에 같이** 실었습니다.
- **검증된 지평은 1주뿐**임을 화면에 적습니다. 주차평균 대비 개선폭이
  1주 +7.65%p → 2주 +1.50%p → 4주 +0.32%p로 급락하기 때문입니다.
- 표본이 얇은 시군은 흐리게 표시하고, 시군마다 CV MAPE와 몇 개 fold를 이겼는지를 붙입니다.
- 쫑상추·상추순·상추솎음은 작기 종료 신호라 가격 타깃에서 빼고 별도 계열로 보여줍니다.

## 갱신

```bash
cd src
../.venv/Scripts/python.exe export_lettuce_webapp.py   # lettuce_app.json (약 10분)
../.venv/Scripts/python.exe forecast_2027.py           # lettuce_forecast_2027.json
```

## 띄우기

```bash
.venv/Scripts/python.exe -m http.server 8731 --directory webapp
```

→ http://localhost:8731/lettuce.html

공개 주소는 https://erato0310.github.io/crop-price-forecast/ 입니다.
